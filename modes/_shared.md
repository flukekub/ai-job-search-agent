# กติกากลาง (ใช้ทุก mode)

## อ่านก่อนเริ่มทุกครั้ง

1. `cv.md`: ข้อเท็จจริงเกี่ยวกับผู้ใช้
2. `config/profile.yml`: ข้อมูลติดต่อ เงินเดือน รูปแบบงานที่รับได้ ภาษา
3. `modes/_profile.md`: เป้าหมายอาชีพ archetype dealbreaker และกฎส่วนตัว (**ถ้าขัดกับไฟล์นี้ ให้ยึด `_profile.md`**)

ถ้ายังไม่มีไฟล์ใด ให้รัน `node scripts/doctor.mjs` แล้วพาผู้ใช้ตั้งค่าก่อน

## ภาษา

- รายงาน สรุป และข้อความถึงผู้ใช้ ให้ใช้ภาษาตาม `language.output` (ค่าเริ่มต้น: ไทย)
- CV และ cover letter ให้ใช้ภาษาตาม `language.cv` หรือภาษาของ JD

## ระบบคะแนน (1–5)

ให้คะแนน 5 มิติ แล้วตัดสินคะแนนรวมจากภาพรวม (ไม่มีสูตรคำนวณ):

| มิติ | วัดอะไร |
|---|---|
| CV Match | requirement ใน JD มีหลักฐานใน cv.md แค่ไหน |
| North Star | ตรงกับ archetype เป้าหมายใน `_profile.md` ไหม (ไม่ตรงเลย = 1 ห้ามฝืนจับคู่) |
| Comp | เงินเดือนเทียบกับเป้าหมายใน profile.yml และตลาด |
| Culture & Work model | รูปแบบงาน (remote/hybrid) ความมั่นคง ขนาดทีม |
| Red flags | ข้อที่ขัดกับ dealbreaker, วีซ่า, ภาษา, สัญญาณประกาศผี (หักคะแนน) |

ความหมายของคะแนน:
- **4.5+** เหมาะมาก สมัครเลย
- **4.0–4.4** เหมาะ คุ้มที่จะสมัคร
- **3.5–3.9** พอได้ แต่แนะนำว่าไม่ควรสมัคร ยกเว้นผู้ใช้มีเหตุผลเฉพาะ
- **< 3.5** ไม่แนะนำ

ถ้าเจอ dealbreaker จาก `_profile.md` ให้คะแนนไม่เกิน 2.5 และบอกเหตุผลตรงๆ

## ความน่าเชื่อถือของประกาศ (แยกจากคะแนน)

ประเมินเป็น **High / Caution / Suspicious** จาก: อายุประกาศ, ความเจาะจงของ JD, requirement ที่ขัดกันเอง, มาจาก aggregator ที่ไม่มีบนเว็บบริษัท
รายงานเป็น "สัญญาณ" ห้ามกล่าวหาว่าบริษัทโกหก

## ความมั่นใจ (Confidence)

ระบุ High / Medium / Low ตามหลักฐานที่มี เช่น JD ไม่ครบหรือไม่มีข้อมูลเงินเดือน = ลดความมั่นใจ แต่ห้ามเดาเพื่อปิดช่องว่าง
